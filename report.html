Топ-5 незакрытых болей рынка

📸

Нет фото моего участка

Все AR работают через живую камеру. Никто не предлагает загрузить фото реального пространства и получить реалистичный рендер.

🌿

Нет outdoor специализации

Все приложения — для indoor. Outdoor = неровные поверхности, тени от деревьев, разные материалы. Никто не решил.

🤝

Нет совместного решения

73% решений о дорогой мебели принимаются вдвоём. Ни одно приложение не поддерживает "пригласить партнёра в проект".

🌡️

Нет климатного советника

Москва, Краснодар, Урал — разные требования к мебели. Никто не объясняет outdoor в контексте российского климата.

📅

Нет симуляции будущего

Как тик выглядит через 3-5 лет? Покупатели боятся это не знать. Никто не показывает aging simulation.

Технологии

AI-стек для "Примерки": 3-8 минут, не 30

Целевое время 30 минут — чрезмерно консервативно. На современных GPU (A10G) реально добиться 3-8 минут. Это кардинально улучшает UX и конкуренспособность.

[Фото участка пользователя] ↓ SAM2 (Meta) → маска зоны размещения [15-30 сек] ↓ ZoeDepth (Intel) → карта глубины / правильный масштаб [10-20 сек] ↓ SDXL Inpaint + ControlNet → вставка мебели [60-120 сек] + IP-Adapter (Tencent) → reference из каталога ТИК (точная мебель) ↓ IC-Light → гармонизация освещения / тени [20-30 сек] ↓ Real-ESRGAN → upscale 2x / финальное качество [15-30 сек] ↓ [Реалистичный рендер → Push-уведомление пользователю]

Риски

Топ-5 рисков и как их митигировать

Низкий adoption "Примерки"

Пользователи скачивают, смотрят каталог, но не делают примерку — сложно, лень загружать фото.

Митигация: Onboarding с "до/после" чужого участка; демо без загрузки своего фото; активный push "хотите увидеть?"

Плохое качество AI-результата

Мебель выглядит неестественно, масштаб неправильный — клиент разочарован. Это хуже чем отсутствие примерки.

Митигация: LoRA fine-tuning + IP-Adapter; гибрид AI + дизайнер для проверки; гарантия "переделаем бесплатно"

Сезонность (зима = тишина)

70-80% продаж outdoor мебели — апрель-август. Зимой трафик и продажи падают. Это факт, не риск.

Митигация: зима = "планирование сезона"; контент-маркетинг; B2B дизайнеры работают круглый год; pre-order со скидкой

Конкуренты скопируют

Конкуренты (Royal Family, новые игроки) могут скопировать функционал "Примерки".

Митигация: скорость — быть первым; 3D база данных как барьер входа; бренд первопроходца не копируется

Рост стоимости AI API

Стоимость OpenAI/Midjourney вырастет или API станет недоступен.

Митигация: 2-3 провайдера; open-source fallback (SDXL самостоятельно); кэширование результатов
