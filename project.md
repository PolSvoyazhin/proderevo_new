# PROJECT.MD — Обзор проекта

## Что это

Веб-приложение **Т▪И▪К** для сайта компании **ПРО ДЕРЕВО** — инструмент продаж premium уличной мебели из тика. Посетитель загружает фото своей террасы или сада, AI расставляет выбранную мебель в реальном пространстве и показывает результат за 3–8 минут. Цель приложения — не онлайн-продажа, а **горячий лид**: убедить клиента позвонить или приехать в шоурум.

## Для кого

Владельцы частных домов, коттеджей и таунхаусов с террасами и садами. Средний чек покупки — 380 000–820 000 руб. Аудитория: Подмосковье, Краснодар, Урал и другие регионы России. Решение о покупке принимается совместно (муж + жена), поэтому в приложении есть функция «Поделиться с партнёром».

## Страницы — уже есть

### `/` — Главная
Первое что видит посетитель. Структура по принципу «Сначала влюби, потом проси»:
- Герой с заголовком, лайв-счётчиком («327 террас») и двумя CTA-кнопками
- Раздел «Как работает Примерка» — 3 шага
- Галерея реальных проектов клиентов (6 карточек с регионами)
- Топ-3 популярных товара
- CTA-баннер с предложением пообщаться с консультантом

### `/catalog` — Каталог
- Фильтрация по категориям: Все / Комплекты / Диваны / Кресла / Столы / Шезлонги
- Карточки товаров: фото-заглушка, цена от/до, размеры, уход, климатические зоны, гарантия
- Кнопки на каждой карточке: «Примерить» и «Спросить»
- CTA-блок внизу страницы

### `/tryout` — Примерка (ключевая страница)
5-шаговый флоу с прогресс-индикатором:
1. **Демо** — показывает готовый результат БЕЗ загрузки фото (снижает барьер входа)
2. **Выбор мебели** — сетка всех товаров, выбор кликом
3. **Загрузка фото** — drag & drop или выбор из галереи + советы по съёмке
4. **Обработка AI** — прогресс-бар с 4 шагами + обучающие карточки во время ожидания
5. **Результат** — фото с мебелью, шеринг (WhatsApp/Telegram/ссылка), форма «Хочу в шоурум» (2 поля)

### `/chat` — Консультант
- AI-чат с аватаром консультанта «Анна» и статусом «Онлайн»
- Быстрые вопросы-кнопки для первого входа
- Анимация «печатания» при генерации ответа
- Встроенные ответы на 6 ключевых тем (Grade A, климат, уход, цены, Урал, гарантия)
- После 3 сообщений пользователя — автоматически появляется форма лида (телефон + «Перезвоните»)
- Кнопка «Попробовать Примерку» — связка двух ключевых функций в петлю

## Дизайн-система

**Философия:** premium, не luxury. Чистый, воздушный интерфейс — фотографии в главной роли, UI служит им.

**Цвета:**
```
Фон:            #FAFAF8  (тёплый белый)
Текст:          #1A1A18  (почти чёрный)
Акцент:         #8B6F47  (цвет тика — главный)
Акцент светлый: #C4A882
Вторичный:      #6B6B67  (подписи, muted)
Граница:        #E8E4DC  (беж)
Поверхность:    #F4F1EB  (карточки, секции)
```

**Типографика:**
- Заголовки: `Playfair Display` (serif, Google Fonts) — создаёт ощущение premium
- Текст: `Inter` (sans-serif, Google Fonts) — чёткость и читаемость

**Компоненты:**
- Кнопки: скруглённые (radius 20–32px), без острых углов
- Карточки: radius 16–20px, тонкая граница `#E8E4DC`
- Тени: минимальные, мягкие

## Ключевые принципы (из исследования)

1. **Барьер после ценности** — демо-режим показывает результат ДО загрузки фото
2. **Петля двух кнопок** — «Примерка» → предлагает «Задать вопрос»; «Чат» → предлагает «Примерить»
3. **Цель = горячий лид** — не онлайн-продажа, а убедить приехать в шоурум
4. **Никакого агрессивного маркетинга** — нет «акций только сегодня», нет всплывающих чатов сразу
5. **Форма заявки** — максимум 2–3 поля (имя + телефон)
